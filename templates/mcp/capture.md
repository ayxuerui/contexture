Save one item of outside material — a meeting transcript or notes, an email, a document, a web page — into the store's inbox, where it waits to be reviewed and filed into notes. It never changes an existing note.

Rules:
- Pass the material in its own words. Copy it through; do not condense, reorder, correct or summarise it. If the source supplies its own summary, keep it in a separate section marked as the source's summary, beside the record rather than instead of it.
- One item per call. Two meetings are two captures.
- `source_type` names where the material came from, lowercased (for example `email`, `meeting`, `web`, `document`). Use the same word the store already uses for that source.
- `source_id` is the source system's own identifier for the item when you have one (a message id, a meeting id, a URL). Leave it out when there is none.

The store refuses material it already holds, and tells you where; tell the person rather than retrying.
