Use __STORE_NAME__ from Claude or ChatGPT

Each download is a plugin for one app. It carries the store's skills and connects the app to the store at __MCP_URL__. You install it once; signing in goes through this store's own login, and the plugin holds no password or key.

Version __VERSION__. When the store's skills change, download it again and install it over the old one.

Claude

Download __CLAUDE_ARCHIVE__

  1. In Claude, open Customize, then Plugins.
  2. Choose Add, then Upload plugin, and pick the file you downloaded.
  3. Start a conversation and ask about something the store holds. The first time, Claude asks you to sign in to the store.

ChatGPT

Download __CHATGPT_ARCHIVE__

  1. If your workspace has an admin, send them the file: an admin uploads a plugin once for the whole workspace.
  2. Otherwise, turn on developer mode in ChatGPT's settings and upload the file there.
  3. Start a conversation and ask about something the store holds. The first time, ChatGPT asks you to sign in to the store.

Changes you make through either app wait in a session of your own until you ask to submit them, and land only once someone approves them on the store's approval page.
