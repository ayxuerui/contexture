Get a second opinion from Claude or ChatGPT

__STORE_NAME__ offers you a second opinion: several AI models of different families review a plan you write, or answer one question, and your app compares what they say. Two things set it up: a skill, which says how to ask, and this server's connector, which runs the review. You set each up once. Signing in goes through this server's own login; nothing you install holds a password or key.

This server's connector

The address to add:

__MCP_URL__

  1. Claude: open Customize, then Connectors. Choose Add custom connector, give it the name second opinion, and paste the address above.
  2. ChatGPT: the plugin below brings this connector with it. To add the connector on its own, open Settings, then Apps & Connectors, turn on developer mode under Advanced settings, then choose Create and paste the address above.
  3. The first time an app asks for a second opinion, it asks you to sign in.

The connector offers four tools, all for the review. It reads no notes and changes nothing.

Claude: the __PLUGIN_NAME__ plugin

  1. In Claude, open Customize, then Plugins.
  2. Choose Add, then Add marketplace, and enter __MARKETPLACE__.
  3. Turn on Sync automatically, so each new release of the skill arrives on its own.
  4. Install the __PLUGIN_NAME__ plugin from that marketplace.
  5. Do not install it beside the __OTHER_PLUGIN__ plugin: that one carries the same skill, with the skills for working in a store.

ChatGPT: this server's plugin

Download __CHATGPT_ARCHIVE__

  1. If your workspace has an admin, send them the file: an admin uploads a plugin once for the whole workspace.
  2. Otherwise, turn on developer mode in ChatGPT's settings and upload the file there.
  3. ChatGPT does not update an uploaded plugin. When contexture releases a new skill, download this file again and upload it over the old one.
